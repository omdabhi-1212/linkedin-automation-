# Voice Calibration Log

This is the running record of every post drafted together during the calibration phase. It's
the actual mechanism behind `LinkedIn_SKILL.md`'s "Keeping This Current" section — instead of
vague "refine over time," every change to the voice profile should trace back to a specific
entry here.

**Two things live in this file:**
1. Posts drafted together, with Om's real feedback on each draft.
2. What that feedback changed in `LinkedIn_SKILL.md`, if anything.

Not every entry produces a change. If a draft nails it on the first try, that's a data point too
— it confirms something in the current voice profile is already right.

## How to Log a Post

Append a new entry at the bottom using the template below. Keep entries in order — the log is
also a timeline of how the voice has actually moved, which matters for the Voice Arc in
`LinkedIn_SKILL.md` (it's the evidence for whether Om has earned more confident framing on a
given topic yet).

After logging, if the feedback implies a durable rule (not a one-off preference), make the
change directly in `LinkedIn_SKILL.md` in the same pass — Voice Profile, banned/allowed phrases,
Post Format, or a new "What GOOD Looks Like" example — and note exactly what changed in the
entry's last field. A log entry that identifies a pattern but doesn't get folded into the skill
file yet is a task, not a finished loop.

```
### Post #[N] — [date] — [one-line topic]

**Pillar:** [1 / 2 / 3]
**Mode:** [Technical / Personal / Informative]
**Input given:** [what Om supplied — a raw note, a topic, a transcript]

**Draft v1:**
[full draft text]

**Om's feedback:**
[verbatim or close to it — "this line sounds like me" / "I'd never say this" / "too polished
here" / "good, keep this exact structure next time"]

**Draft v2 (if a revision was needed):**
[full draft text, or "not needed"]

**Final approved text:**
[what actually shipped, or "not yet approved"]

**What changed in LinkedIn_SKILL.md:**
[the specific section and edit — e.g. "added 'that tracks' to Phrases that sound like Om" — or
"nothing, this draft confirmed the current profile is accurate"]

**Status:** [Approved and posted / Approved, not yet posted / Reworked / Scrapped]
```
